Most productivity tools are optimized for capture. Capture matters, but it is only the first step. The harder problem is continuity: what happens to an idea after it is written down?

For knowledge work, a useful personal system needs four linked layers:

1. A place to capture fragments before they are polished.
2. A comment layer where thinking can be challenged, expanded, and clarified.
3. AI assistance that proposes the next concrete move.
4. Todos that preserve the link back to the original thought.

When these layers are disconnected, the user has to do the integration work manually. A note becomes a task only if someone remembers to copy it. A task loses context because the original discussion is somewhere else. AI suggestions vanish because they were generated in a separate chat.

The direction behind integ.life is different: keep the record connected. A note can receive a comment, the comment can become an action, and the action can still point back to the original idea.

That changes the role of a notes app. It is no longer a passive archive. It becomes the entry point for an execution system.

## The useful unit is not a document

The useful unit is a chain:

- thought
- interpretation
- decision
- task
- evidence

That chain is what makes future review possible. You can see not only what was completed, but why it mattered and where it came from.

## What to optimize for

The system should make the smallest next action obvious. It should reduce the distance between thinking and doing. It should preserve enough context that the user can return days later and continue without rebuilding the whole mental state.

That is the promise of an AI-assisted personal operating system: not another place to store text, but a way to turn thinking into visible progress.
