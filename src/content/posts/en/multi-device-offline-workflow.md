Real work does not happen on one device.

You may plan on a web app, capture a thought on a phone, start a timer from a watch, and check progress from a Mac menu bar. If the system only works well in one place, the user is forced to adapt their day to the tool.

The better product principle is continuity across the devices people already use.

That requires more than shipping several apps. The important details are:

- fast capture from the current device
- offline writes when the network is unavailable
- conflict-safe sync when the device reconnects
- the same todo, goal, note, and focus record across every surface

## Mobile capture is not the same as desktop work

A phone is good for quick entry. A desktop is better for review and editing. A watch is good for low-friction timers and reminders. Each surface should do the job it is naturally good at.

The system should not pretend every device is the same. It should preserve one connected record while letting each interface stay focused.

## Offline-first is a workflow feature

Offline support is often treated as technical polish. For productivity, it is a workflow feature. If an idea appears while you are offline, the system should still accept it. If a focus session starts away from Wi-Fi, it should still count.

Continuity is what makes a personal operating system trustworthy.
